# 三叶 Trefoil Group — 研究组主页

依托云南大学软件学院人工智能学院、云南省软件工程重点实验室，由校内与校外合作者共同发起。

静态站点。**无构建步骤、无外部依赖、无 CDN、无外部字体**——克隆下来直接用浏览器打开 `index.html` 就能跑，也便于国内访问。

## 文件

| 文件 | 作用 | 需要改吗 |
|---|---|---|
| `data.js` | **全站内容**：文案、研究方向、成员、合作伙伴、招募与合作、联系方式，全部中英双语 | ✅ 日常只改这个 |
| `index.html` | 页面骨架 + 内联 SVG 图标与三叶结符号 | 增删整个区块时才改 |
| `index.css` | 全部样式 | 调整视觉时才改 |
| `app.js` | 渲染、语言切换、导航、滚动高亮 | 一般不用改 |
| `favicon.svg` | 站点图标（三叶结） | 不用改 |
| `imgs/` | 人物照片、首屏底图、公众号二维码 | 换人换图时改 |
| `imgs/brand/` | 公众号头像的几个版本（站点本身不引用） | — |

## 本地预览

任意静态服务器都行，例如：

```bash
python3 -m http.server 8123
```

然后打开 <http://localhost:8123>。直接双击 `index.html` 也可以。

## 怎么改内容

`data.js` 里所有文字都是 `{ zh: "中文", en: "English" }`，两种语言都要填，缺 `en` 会回落成中文。

### 加一位成员

在 `team` 数组里加对象，照片放进 `imgs/`：

```js
{
  role:  { zh: "成员", en: "Member" },
  name:  { zh: "姓名", en: "Name" },
  affil: { zh: "单位　身份", en: "Affiliation, role" },
  bio:   { zh: "一段中文简介。", en: "An English bio." },
  photo: "./imgs/xxx.jpg",
  photoPos:  "50% 30%",   // 方形裁切的取景点，第二个值越小取景越靠上
  photoZoom: 1.2,         // 放大倍数；证件照拍得远、脸小就调大
  links: { email: "...", site: "...", linkedin: "..." }
}
```

`photoPos` 与 `photoZoom` 共用同一个锚点（CSS 里 `object-position` 与 `transform-origin` 都取它），所以放大时脸不会跑偏。加新人先填 `photoZoom: 1`，看一眼再调。

照片建议**竖构图**，长边压到 900px 以内、体积 ≤120KB。卡片里按 4:5 裁切。

### 加一个合作伙伴

`partners.people` 数组，顺序即页面顺序。**合作伙伴不显示研究方向，也不放任何链接**（业主的明确要求）：

```js
{
  name:  { zh: "姓名 称谓", en: "Name, title" },
  role:  { zh: "合作研究者", en: "Research collaborator" },
  affil: { zh: "单位与科室", en: "Institution and department" },
  photo: "./imgs/xxx.jpg",   // 没有照片就用下面的 mark
  mark:  "姓",                // 无照片时显示的姓氏字标
  links: {}
}
```

`tags` 字段仍在数据里但**不渲染**，留着备用。

### 改研究方向

`areas` 数组，平铺列表，顺序即页面顺序与编号。

## 设计语言

按业主读博时的旧站 [crr.ucc.ie](https://crr.ucc.ie) 重做：

- **章节标题居中、40px、粗体无衬线**，下面一条 55px 橙色短线
- 章节留白 `100px`
- 单一强调色 **橙 `#ff6905`**（CRR 品牌色），深靛 `#222042` 用于成员章
- **全无衬线**（CRR 用 Hind，此处换成系统字体栈）
- 研究方向卡**悬停整卡反黑**，取自 CRR 的 `.three-grids-columns:hover`
- 首屏三叶结的描边动画取自 CRR 的 `@keyframes line`（`stroke-dasharray`）；`<path>` 上写了 `pathLength="1"`，所以 dasharray 直接用 1 就是整条路径
- 无阴影卡片、无圆角色块、无渐变底、无滚动渐显、无轮播

## 自适应

断点：`1200 / 1100 / 960 / 780 / 520`。另外用 `@media (pointer:coarse)` 放大触摸目标、`@media (hover:none)` 关掉悬停反黑（避免手指点一下「粘住」反色），`@media (prefers-reduced-motion:reduce)` 停掉纽结动画。

实测覆盖（无头 Chrome 逐元素量，中英各一轮）：

```
320×568  375×667  430×932  852×393(横)  744×1133
1024×1366  1280×800  1440×900  1920×1080
```

全部零横向滚动、零越界元素。

## 无障碍

- 跳转到主要内容的 skip link
- 图标链接用 `aria-label`，随语言切换重新渲染
- `<ol class="panel__list">` 用了 `display:contents` 参与外层网格，所以补了 `role="list"` 保住列表语义
- 焦点样式在深色区改用白色描边，全站没有 `outline:none`
- 汉堡菜单有 `aria-expanded`
